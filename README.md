Реализация [шифра Цезаря](https://ru.wikipedia.org/wiki/Шифр_Цезаря) на С++. 

Формат входного файла:

`Ключ (положительный для сдвига вправо, отрицательный для сдвига влево)` 

`Текст`

В выходном файле указывается оригинальный текст, зашифрованный и расшифрованный для проверки правильности работы программы.
